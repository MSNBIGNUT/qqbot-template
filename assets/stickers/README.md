# assets/stickers/ —— 表情包素材目录（默认空）

这个目录在模板仓库里**只保留结构，不含素材**：原来那些图是某个私人角色的形象资产，
不随模板分发。

## 怎么放自己的表情包

1. 把图片直接放进本目录，文件名就是表情名字，例如 `开心.jpg`、`无语.png`。
2. 支持 `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`，单张建议 ≤ 2 MB、128×128。
3. 文件名里的逗号是别名分隔符：`卖萌,撒娇.jpg` 会被识别成「卖萌」和「撒娇」两个名字。
4. 重启机器人即可，`listStickers` 会自动扫描；模型就能调用 `send_sticker` 发出去。

## 注意

- `.gitignore` 已排除本目录下的图片，避免把私人素材提交上去。
- 只在私聊/群聊里让机器人「存下来」的图，也会写进这里或 `data/`（取决于存图实现），
  注意别把别人的图当素材分发。
- `assets/` 根目录下的角色参考图（如果有）同样不随仓库分发；画图功能会用它们锁形象，
  没有也能用，只是生图时没有固定的长相参考。
